# 華山 10F · 空間工作室

6.1.0 · 可在瀏覽器操作的 3D 辦公室材質、展場配置與空間互動工具。

[開啟網站](https://jspusa.github.io/test/)

## 使用方式

在上方選擇 **辦公室** 或 **展場**。電腦可拖曳旋轉、滾輪縮放、右鍵平移；手機可單指旋轉、雙指縮放與平移，下方按鈕開啟編輯及視角面板。

### 辦公室

- 點選桌面、擋腳板、牆面或地板更換材質。
- 辦公桌面與櫃檯面連動；擋腳板與櫃體正、側面連動。
- 可調整顏色、光澤、紋理及桌櫃高度，或上傳自己的材質圖片。共 34 款材質，按石材、皮革、木紋及其他分類。桌面先顯示石紋；原素色選項皆具有皮革紋路。
- 桌面設備含 49 吋 Odyssey OLED G9 G93SD（LS49DG932SCXZW、1800R）曲面螢幕、Studio Display、14 吋 MacBook Pro 及位於右手側的立式滑鼠外型。辦公室與展場可使用同款木地板。

### 展場

- 選 3 × 3、6 × 3、6 × 6、9 × 6 m 攤位，或自訂尺寸及地板。
- 點模組卡片加入物件；電腦也可拖進場景。
- 點物件調整寬高深、位置、角度及顏色。欄位以 cm 編輯。
- 電腦直接拖物件；手機點選後即可拖曳，空白處旋轉視角。
- 支援格線吸附、展示台等支承面自動疊放、複製、旋轉及復原／重做。
- 圖片可指定正面、背面、左側、右側或頂面，也可從電腦直接拖到模型的面。每個物件目前保留一張貼圖，可換面、替換或移除。
- 「方案」可載入範例、清空、匯入／匯出 JSON、另存 HTML 及匯出 DXF。

## 平面搭建

在展場按 **「平面搭建」**，可隨時按 **「看 3D」** 檢查結果。

1. **直接配置**：拖曳櫃子；空白處拖曳平移，滾輪或雙指縮放。選取後由「編輯」輸入尺寸、位置、角度；R 旋轉，Delete 刪除，⌘／Ctrl Z 復原。
2. **畫牆**：設定牆高與厚度，點起點與終點，或拖出隔牆。隔牆可繼續修改尺寸及材質。
3. **照底圖搭建**：按「＋ 底圖」加入 JPG／PNG／WebP 平面圖。在「標定」輸入一段已知長度（cm），再點圖上兩端；可用「移底圖」對齊攤位，調透明度後照圖畫牆、擺放模組。

2D 與 3D 共用配置，底圖、標定比例及隔牆會隨方案一起保存。底圖供照圖搭建，不會自動辨識牆線。

展場提供烤漆、橡木、胡桃木、石紋、拉絲金屬與織物；模型含板件圓角、接縫、踢腳、五金及玻璃層板。切換材質後仍可自訂顏色。

### 自由行走

電腦以 **WASD／方向鍵移動、滑鼠環視、Shift 切換跑步、Space 跳躍、V 切換第一／第三人稱**。手機使用左搖桿移動、右側畫面拖曳環視；輕推走路、推滿跑步，右側輕點兩下跳躍，不需另按跑步鍵。移動有家具碰撞及落地判斷，另附位置小地圖。

靠近座椅按 **F** 坐下，再按 F 起身；手機按畫面的「坐下／起身」。**「動作」** 可選打招呼、跳舞或躺下，再選「回到站姿」結束。人物採 Microsoft Rocketbox MIT 授權商務人物；部分動作是本工具製作的骨架動畫。

### 加入與駕駛車輛

在展場「模組」加入 **911 Targa 4 GTS · 龍膽藍**，靠近駕駛側按 **F 上車**，再按 F 下車。W／S 前進與倒車、A／D 轉向、**Space 煞車**、V 切換視角。手機按「上車」後直接使用左搖桿：向前推前進、向後拉減速及倒車、左右轉向；右側拖曳環視。

車輛為依 Porsche 992.2 Targa 4 GTS 官方外部尺寸製作的原創外型示意，含龍膽藍車身、駝色內裝、Targa 後玻璃及可轉向車輪。它不是原廠 CAD，使用低速空間駕駛計算。車模和人物動作在需要時才載入。

## 儲存與交付

- **4K 出圖**：匯出 3840 × 2160 PNG；可選快速或精細光影渲染。精細模式依裝置效能可能需數分鐘，可取消。
- **另存網頁**：下載含目前配置、圖片及視角的完整 HTML，之後可離線開啟；首次下載需要網路。
- **場景 JSON**：保存可繼續修改的方案。
- **CAD 配置 DXF**：毫米單位的平面輪廓、模組尺寸與離地高度，供設計討論。它不是施工詳圖，不含五金、板件拆解或結構計算。

6.1 沿用既有瀏覽器方案。舊版仍使用預設木地板色的方案會更新為同款木地板色；自行選色、上傳圖片及其他配置會保留。

變更自動儲存在目前瀏覽器。重要方案請另存 HTML 或 JSON；清除瀏覽資料、換瀏覽器或換裝置，不會自動同步。上傳圖片在本機處理，匯出檔案會包含圖片。

## 手機全螢幕

按上方「全螢幕」，可隨時按同一位置退出。若瀏覽器不支援原生全螢幕，會改用頁面沉浸模式。iPhone 可在 Safari 使用「分享 → 加入主畫面」，之後從主畫面圖示開啟以隱藏 Safari 工具列。加入主畫面不等於下載完整離線版。
