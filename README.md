# 華山 10F · 主管室材質工作室

[開啟互動空間](https://jspusa.github.io/test/)

- 手機先顯示完整 3D 空間；材質與視角面板可收合。
- 辦公桌面與櫃體檯面、落地擋腳板與櫃體正側面連動換材質。
- 第一人稱行走、全螢幕觀看、牆面與天花板顯示控制。
- 3840 × 2160 PNG 出圖；精細光影渲染依裝置可能需數分鐘。
- 「另存網頁」可下載含目前方案的完整離線 HTML。

## 手機操作

單指旋轉、雙指縮放和平移。下方「材質」可打開面板，一邊更換材質、一邊查看模型；「視角」可切換俯視或家具近看。

按「走進室內」後，左手搖桿移動、右手拖曳環視。按「結束行走」返回室內視角。

右上角「視線：通透」方便直接看家具；天花板可選自動、隱藏或顯示。「全螢幕」會依瀏覽器支援進入原生全螢幕或沉浸模式，右上角可退出。iPhone 若仍有 Safari 工具列，可用 Safari 分享選單「加入主畫面」，再由主畫面圖示開啟。

## 電腦操作

拖曳旋轉、滾輪縮放、右鍵平移。第一人稱使用 WASD／方向鍵或畫面按鈕移動，拖曳環視；Esc 離開行走。

## 畫質與資料

預設「清晰」模式，保留抗鋸齒並依螢幕解析度調整畫布。可在「空間 → 畫面品質」選省電或精緻。精細渲染與離線文件依操作載入。

公開網站及其離線下載不含原始圖面或現況照片；這些資料僅保留在桌面版。方案保存在使用者自己的瀏覽器；上傳材質圖片只在該頁處理。

窗外是 AI 示意背景；空間及材質用於設計討論，施工尺寸與板材請依設計圖及廠商實物確認。
