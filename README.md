# 華山 10F · 主管室材質工作室

[開啟互動空間](https://jspusa.github.io/test/)

- 室內提案、第一人稱行走與全螢幕。
- 桌面與櫃檯面、落地擋腳板與櫃體正側面連動換材質。
- 3840 × 2160 PNG 出圖；精細光影渲染依裝置可能需數分鐘。
- 「另存網頁」可下載含目前方案的完整離線 HTML。

## 操作

拖曳旋轉、滾輪縮放、右鍵平移。按「走進室內」後，用 WASD／方向鍵或畫面按鈕移動，拖曳環視；Esc 離開行走。

## 載入與資料

首頁以流暢模式優先載入互動空間；可在「空間 → 畫面品質」切換細緻，4K出圖保留完整光影。精細渲染與離線文件依操作載入。公開網站及其離線下載不含原始圖面或現況照片；這些資料僅保留在桌面版。方案保存在使用者自己的瀏覽器；上傳材質圖片只在該頁處理。

窗外是 AI 示意背景；空間及材質用於設計討論，施工尺寸與板材請依設計圖及廠商實物確認。
